# 本機 PDF 壓縮小工具

這個工具只在 Windows 電腦上處理一個 PDF，不會上傳檔案。原始檔案不會被覆寫；結果會儲存在同一資料夾，檔名加上 `-compressed`。

## 第一次使用

1. 安裝免費的 [Ghostscript for Windows](https://ghostscript.com/releases/gsdnld.html)。安裝時使用預設選項即可。
2. 安裝完成後，關閉並重新開啟本工具。
3. 連按兩下 `Start-PdfCompressor.cmd`。

## 使用方式

1. 拖放一個 PDF 到視窗中，或按「選擇 PDF 檔案」。
2. 選擇壓縮強度：
   - 清晰：優先保留圖像、文字與表格品質。
   - 平衡：一般閱讀建議，兼顧品質與大小。
   - 最小：盡量減少檔案大小，掃描圖片可能略為模糊。
3. 按「開始壓縮」，完成後按「開啟結果資料夾」。

## 限制與安全性

- 第一版一次只處理一個 PDF。
- 受密碼保護、損壞或非 PDF 的檔案會顯示原因，且不會修改原檔。
- Ghostscript 與此工具都可在沒有網路時使用；網路只在第一次下載 Ghostscript 時需要。
